# Criando e Treinando a Minha Primeira Rede Neural

Projeto educacional para aprender, na prática, como criar e treinar uma rede
neural. A proposta é registrar a implementação e os experimentos à medida que
o projeto evolui.

## O exemplo

Este exemplo usa TensorFlow.js para classificar uma pessoa em uma de três
categorias (`premium`, `medium` ou `basic`). O modelo recebe sete valores
numéricos: idade normalizada, cor e localização codificadas.

O treinamento usa apenas três exemplos ilustrativos. Os resultados servem para
estudo e não representam um modelo adequado para uso real.

## Executar

Requisitos: Node.js 18 ou superior e npm.

```bash
npm install
npm start
```

O script treina o modelo e imprime as probabilidades previstas para uma pessoa
de demonstração.

## Objetivos

- Explorar os componentes básicos de uma rede neural.
- Entender o processo de treinamento e avaliação de um modelo.
- Documentar as escolhas e os aprendizados do projeto.
