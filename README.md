# Criando e Treinando a Minha Primeira Rede Neural

Projeto educacional para aprender, na prática, como criar e treinar uma rede
neural. A proposta é registrar a implementação e os experimentos à medida que
o projeto evolui.

## Objetivos

- Explorar os componentes básicos de uma rede neural.
- Entender o processo de treinamento e avaliação de um modelo.
- Documentar as escolhas e os aprendizados do projeto.

## Estado do projeto

O projeto está em fase inicial. No momento, este repositório contém apenas a
documentação e a licença; o código da rede neural e as instruções para executá-lo
ainda serão adicionados.
